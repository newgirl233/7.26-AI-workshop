项目说明

① 项目介绍

核心目标：本项目旨在利用 AI 语音交互技术，为视障人士提供一个便捷、友好的杭州旅游导览工具。通过语音提问，用户可以获得关于杭州景点、历史、文化和美食的详细介绍。

整体架构：采用纯前端方案，包含三大核心模块——语音识别模块（Web Speech API 将用户语音转为文字）、AI 对话模块（大语言模型作为智能导游生成回答）、语音合成模块（Web Speech API 将回答朗读出来）。无需后端服务器，浏览器即可运行。

设计思路：围绕"无障碍"和"包容性"理念，界面采用高对比度配色、大尺寸交互元素、清晰的 ARIA 标签和键盘导航支持。交互流程上，用户只需点击麦克风按钮说出问题，系统便会自动完成"听→理解→回答→朗读"的完整闭环。

② AI 使用披露

本项目的 HTML、CSS、JavaScript 代码由 AI 助手辅助生成，开发者已对 AI 生成的代码进行人工审查和调整，确保代码的正确性和安全性。

语音识别与语音合成功能使用浏览器内置的 Web Speech API，不涉及第三方 AI 服务。
